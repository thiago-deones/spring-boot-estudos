# Spring Boot Estudos

Repositório dedicado aos meus estudos e à evolução no desenvolvimento Backend com Java e Spring Boot.

Aqui reúno projetos práticos, exercícios e desafios desenvolvidos durante minha jornada de aprendizado, aplicando conceitos de desenvolvimento de APIs REST, persistência de dados, integração com serviços externos, organização em camadas e boas práticas de programação.

## Tecnologias e ferramentas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- H2 Database
- Maven
- JUnit e Mockito
- Spring Validation
- OpenFeign
- Springdoc OpenAPI
- Lombok
- Git e GitHub

*As tecnologias utilizadas variam de acordo com cada projeto.*

## Objetivo

Construir uma base sólida em desenvolvimento Backend com Java e Spring Boot, desenvolvendo projetos práticos e evoluindo gradualmente na aplicação de conceitos, ferramentas e boas práticas utilizadas no mercado de trabalho.
